## 1. Основы

### Комментарии

```lime
// Это однострочный комментарий

/*
  Это многострочный
  комментарий
*/
```

### Переменные

Объявление переменной всегда начинается с ключевого слова `var`. Присваивание использует `=`.

```lime
var name = "Lime"
var version = 1.0
var is_stable = false
var hex_num = 0xFF // Поддержка шестнадцатеричных чисел
```

### Изменение значений

Поддерживается изменение простых переменных, полей объектов и элементов массивов.

```lime
var counter = 0
counter = 10
counter += 5  // Также доступны: -=, *=, /=
```

## 2. Структуры данных

### 📦 Массивы (0-индексация!)

В отличие от Lua, массивы в Lime начинаются с **0**. Поддерживаются отрицательные индексы (как в Python).

```lime
var fruits = ["apple", "banana", "cherry"]

print(fruits[0])   // "apple"
print(fruits[-1])  // "cherry" (последний элемент)
print(fruits.len()) // 3
```

### 📖 Словари (Dict)

Ключами могут быть строки, идентификаторы или выражения в скобках.

```lime
var user = {
    name: "Alice",
    "age": 25,
    (1 + 1): "two" // Динамический ключ
}

print(user.name) // "Alice"
```

### 🧩 Кортежи (Tuples)

Неизменяемые последовательности, разделяемые запятыми в круглых скобках.

```lime
var coords = (10, 20, 30)
var single = (42,) // Кортеж из одного элемента (обратите внимание на запятую)
```

## 3. Операторы


| Тип                                  | Операторы                                                                              |
| :-------------------------------------- | :---------------------------------------------------------------------------------------------- |
| **Арифметические**        | `+`, `-`, `*`, `/`, `//` (целочисленное деление), `%`, `^` (степень) |
| **Сравнения**                  | `==`, `!=`, `>`, `<`, `>=`, `<=`                                                                |
| **Логические**                | `&` (AND), `                                                                                    |
| **Конкатенация строк** | `..`                                                                                            |
| **Пайплайн (Конвейер)** | `>>`                                                                                            |

### 🌟 Оператор пайплайна (`>>`)

Передает результат левого выражения как **первый аргумент** в правое выражение (функцию или метод).

```lime
var numbers = [1, 2, 3]

// Эквивалентно: sum(map(numbers, fn(x) = x * 2))
var result = numbers 
    >> map(fn(x) = x * 2) 
    >> sum()

print(result) // 12
```

## 4. Управление потоком

### Условия (`if` / `elif` / `else`)

```lime
var score = 85

if score >= 90 {
    print("Отлично")
} elif score >= 70 {
    print("Хорошо")
} else {
    print("Нужно подтянуть")
}
```

### Циклы

**Цикл `loop` (аналог `while`):**

```lime
var x = 0
loop x < 5 {
    print(x)
    x += 1
}
```

**Классический цикл `for` (как в C):**

```lime
// for (инициализация, условие, шаг)
for i = 0, 10, 2 {
    print(i) // 0, 2, 4, 6, 8
}
```

**Цикл `for ... in` (по коллекциям):**

```lime
var items = ["a", "b", "c"]
for item in items {
    print(item)
}

// Для словарей можно получить ключ и значение
var dict = {x: 10, y: 20}
for k, v in dict {
    print(k + " = " + v)
}
```

### Управление циклом

* `stop` — аналог `break` (немедленный выход из цикла).
* `next` — аналог `continue` (переход к следующей итерации).

### Ветвление `match` (аналог `switch`)

```lime
var status = "error"

match status:
    case "ok" {
        print("Успех")
    }
    case "error" {
        print("Ошибка")
    }
    case _ { // Символ подчеркивания работает как "default"
        print("Неизвестный статус")
    }
```

## 5. Функции и лямбды

### Объявление функции

```lime
fn greet(name, greeting = "Hello") {
    ret greeting + ", " + name + "!"
}

print(greet("Lime")) // "Hello, Lime!"
```

*(Ключевое слово для возврата значения: `ret`)*

### Лямбда-выражения (стрелочные функции)

Если тело функции состоит из одного выражения, можно использовать `=` вместо `{}`.

```lime
var add = fn(a, b) = a + b
print(add(5, 3)) // 8

// Анонимная функция с блоком кода
var process = fn(x) {
    var temp = x * 2
    ret temp + 1
}
```

## 6. Реактивность (Signals)

Встроенная система реактивного программирования (вдохновлена SolidJS/Vue).

```lime
// 1. ref: изменяемое реактивное значение
var count = ref(0)

// 2. live: вычисляемое значение (обновляется автоматически)
var double_count = live(fn() = count.value * 2)

// 3. watch: выполняет код при изменении зависимостей
watch(fn() {
    print("Count изменился! Новое значение:", count.value)
})

// Изменение значения запускает watch и пересчитывает live
count.value = 5 
// Вывод: "Count изменился! Новое значение: 5"
// double_count.value теперь равен 10
```

*Доступ к значению всегда осуществляется через свойство `.value`.*

## 7. Модули и C-Interop (FFI)

### Импорт модулей Lime

```lime
// Загружает файл "utils.lm" из текущей директории
load "utils"

// Загружает "libs/network/setup.lm" (локально или из глобальной папки libs)
use "network"
```

### Описание C-структур

```lime
struct Vector2 {
    x: float,
    y: float
}

var pos = Vector2(10.5, 20.0)
print(pos.x) // 10.5
```

*Поддерживаемые типы:* `int` (или `i`), `float` (или `f`), `double` (или `d`), `bool` (или `b`), `string` (или `s`), `void*` (или `p`), а также указатели (`int*`, `float*` и т.д.).

### Подключение C-библиотек (FFI)

```lime
// Подключает libmath.dll / libmath.so
usec "libmath" {
    rule: "double calculate_sum(double a, double b);"
} as math_lib

var result = math_lib.calculate_sum(5.5, 4.5)
```

*Компилятор автоматически ищет библиотеку в папке `libs/`, текущей директории и системных путях.*

### Вызов методов структур

Методы для C-структур объявляются через двоеточие:

```lime
Vector2:normalize(self) {
    var len = (self.x ^ 2 + self.y ^ 2) ^ 0.5
    self.x = self.x / len
    self.y = self.y / len
}

// Вызов метода (обратите внимание на :: вместо .)
pos::normalize()
```

## 8. Встроенные расширения

Стандартная библиотека (`config.py`) автоматически добавляет удобные методы к базовым типам.

### 📝 Методы строк


| Метод            | Описание                                  | Пример                            |
| :-------------------- | :------------------------------------------------ | :-------------------------------------- |
| `.split(sep)`         | Разбивает строку на массив | `"a,b".split(",")` → `["a", "b"]`      |
| `.trim()`             | Удаляет пробелы по краям     | `"  hi  ".trim()` → `"hi"`             |
| `.startswith(prefix)` | Проверка начала строки        | `"hello".startswith("he")` → `true`    |
| `.endswith(suffix)`   | Проверка конца строки          | `"test.txt".endswith(".txt")` → `true` |
| `.contains(sub)`      | Содержит ли подстроку          | `"abc".contains("b")` → `true`         |
| `.replace(old, new)`  | Замена подстроки                   | `"a-b".replace("-", "_")` → `"a_b"`    |
| `.isdigit()`          | Состоит ли только из цифр    | `"123".isdigit()` → `true`             |

### 🔢 Методы чисел


| Метод             | Описание                                            | Пример                |
| :--------------------- | :---------------------------------------------------------- | :-------------------------- |
| `.abs()`               | Модуль числа                                     | `(-5).abs()` → `5`         |
| `.round()`             | Округление до ближайшего целого | `(3.7).round()` → `4`      |
| `.clamp(min, max)`     | Ограничение диапазона                   | `(15).clamp(0, 10)` → `10` |
| `.isEven()` / `.odd()` | Проверка на четность/нечетность | `(4).isEven()` → `true`    |
| `.sign()`              | Знак числа (-1, 0, 1)                              | `(-10).sign()` → `-1`      |
| `.fract()`             | Дробная часть числа                        | `(3.14).fract()` → `0.14`  |

### 📦 Методы массивов


| Метод                 | Описание                                                                                                       |
| :------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| `.push(val)` / `.add(val)` | Добавить элемент в конец                                                                          |
| `.pop()`                   | Удалить и вернуть последний элемент                                                     |
| `.shift()`                 | Удалить и вернуть первый элемент                                                           |
| `.first()` / `.last()`     | Получить первый/последний элемент                                                        |
| `.len()`                   | Длина массива                                                                                              |
| `.clear()`                 | Очистить массив                                                                                          |
| `.map(fn)`                 | Вернуть новый массив, преобразованный функцией                                |
| `.sum()`                   | Сумма всех числовых элементов                                                                |
| `.tostr()`                 | Красивое строковое представление (JSON-подобное)                                 |
| `.ptr(type)`               | **FFI:** Преобразует массив в C-массив (`ffi.new`) для передачи в C-функции |
